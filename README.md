# 金山云医疗智能体展台演示

封面 + 20 页内容轮播，包含三段演示视频。封面停留 8 秒，随后显示“医疗智能体平台总体架构”，其余内容保持原有相对顺序。最后一段视频结束后回到封面，再继续轮播。

访问地址：https://vincent1943-cyber.github.io/kax-exhibit/

## 文件

- index.html：展台页面及三维架构
- cover.png：金山云与武汉协和医院双 Logo 封面
- ontology-demo.mp4：本体+知识库v1.1（正文第6页）
- agent-build-demo.mp4：智能体构建v1.2（正文第11页）
- xiaohe-demo.mp4：数字小和v1.1（正文第20页）
- .nojekyll：直接发布静态文件

上述文件均放在仓库根目录。Settings → Pages 选择 main 分支、/(root)。

## 播放

打开后自动轮播；浏览器拦截自动全屏时，点击全屏入口。
视频默认静音，右上角可开启声音；空格暂停/继续，方向键切页。
左侧持续自转，手动切页后继续轮播。暂停自转按钮仅影响架构。

视频均保留原始分辨率、完整时长和音轨。三段视频均采用 H.264 网络压缩版本，并优化 MP4 文件布局。

## 三维架构

原第 8—11 幕现为正文第 9—12 页，均对应智能体开发技术栈。自转速度为每秒 4.356°（在上一版基础上再提高 10%，约 82.6 秒一周）。各层增加立体器件、接口细节与内部动态数据连线。

左上角使用用户提供的金山云 Logo，已内嵌在页面中。

## 右侧内容排版

17 个图文页根据可用空间分别调整字号、卡片与间距，主体内容目标覆盖可用高度约 88%，同时避免超出可见区域。统一模型网关页采用两行治理卡片；医生数字分身页的英文副标题独立显示。封面、正文顺序与三段视频播放保持原有行为。
